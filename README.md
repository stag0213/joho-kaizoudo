# 画像解像度チェンジャー (Image Resolution Changer)

ブラウザ内（クライアントサイド）だけで完結する、軽量で安全な画像解像度変換Webアプリケーションです。

---

## 🌟 特徴

* **完全クライアントサイド処理**: 画像データはサーバーに一切送信されず、すべてお使いのブラウザ上で処理されます。プライバシーや機密データも安心して扱えます。
* **リアルタイム・直感的プレビュー**: 画面が左右に2分割され、スライダーを動かすだけで画質の変化（ぼやけ・モザイク感）や推定ファイルサイズを瞬時に比較・確認できます。
* **位置・サイズ完全同期**: 左右の表示位置や高さがミリ単位で同期されているため、元画像と変更後画像の劣化度合いを視覚的に一目で確認できます。
* **ノーサーバー・軽量動作**: HTML/CSS/JavaScriptのみで構築されているため、GitHub Pagesなどの静的ホスティングサービスで簡単に公開・運用できます。

---

## 🛠️ 主な機能

1. **元画像の読み込み（左画面）**
   * ドラッグ＆ドロップ、またはファイル選択ダイアログによる読み込み
   * 対応フォーマット: `JPEG`, `PNG`, `WebP`
   * オリジナル解像度（横px × 縦px）およびファイルサイズの自動計測・表示
2. **解像度の調整・出力（右画面）**
   * `10%` 〜 `100%` の無段階スライダー調整
   * 変更後解像度および推定ファイルサイズのリアルタイム表示
   * 画質の劣化具合を等倍表示で確認できる同期プレビュー
   * ワンクリックでローカルへのダウンロード保存（ファイル名: `元ファイル名_resized.拡張子`）

---

## 🚀 使い方（ローカル実行）

1. 本リポジトリをクローンまたはZIPダウンロードします。
2. フォルダ内の `index.html` ファイルをブラウザ（Chrome, Edge, Safari, Firefox等）でダブルクリックして開きます。
3. 左側のエリアに画像をドラッグ＆ドロップし、右側のスライダーで解像度を調整してダウンロードします。
